JavaScript cerca di accettare “qualunque” codice gli venga proposto. Ad esempio, in situazioni in cui gli operatori sono applicati a tipi di dati “scorretti”, JavaScript effettua delle conversioni automatiche silenziose, dette type coercition, essendo un linguaggio weakly typed. Anche nell’uso di == e != viene effettuata type coercition. Se si vuole effettuare una comparazione precisa senza casting è necessario usare gli equivalenti \==\= e !\==\=. Ad esempio, 3 == '3' produce true, mentre 3 \==\= '3' produce false.
